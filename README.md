# Custom PDF Viewer with JavaScript
This repo is an adaptation of [Create a Custom PDF Viewer With JavaScript](https://www.youtube.com/watch?v=ydCSSgwZjzs&list=PLillGF-RfqbbnEGy3ROiLWk7JMCuSyQtX&index=14&pp=iAQB) by Traversy Media. 

I followed the tutorial to learn followings:
- Load a pdf in a web page
- Add a navbar and pagination at the top
- Sheild file load errors
- Integrate `pdf.js`
